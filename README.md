# 📊 Customer_behavior_Analysis (Data Analytics Project)

## Overview

This project demonstrates an end-to-end data analytics workflow, including data extraction, cleaning, exploratory data analysis (EDA), SQL-based data querying, dashboard creation, and business reporting. The goal is to transform raw data into actionable insights through a structured analytical process.

---

## Dataset

**Source:** [customer_behavior_Analysis.csv]

### Dataset Description

* Number of Records: 3990
* Number of Features: 100
* Data Type: Structured Dataset
* Domain: (Sales)

## Project Workflow

### 1. Data Loading

* Imported dataset using Python.
* Verified data structure and types.
* Performed initial inspection.

### 2. Data Cleaning

* Removed duplicates.
* Handled missing values.
* Corrected inconsistent data formats.
* Processed outliers where applicable.

### 3. Exploratory Data Analysis (EDA)

* Generated descriptive statistics.
* Analyzed distributions and trends.
* Identified correlations and patterns.
* Created visualizations for better understanding.

### 4. SQL Analysis

* Loaded data into MySQL Server.
* Executed SQL queries for:

  * Aggregations
  * Filtering
  * Joins
  * Ranking
  * Trend analysis
  * KPI calculations

### 5. Dashboard Development

* Connected Power BI to processed data.
* Designed interactive reports and visualizations.
* Created KPI cards, charts, and filters.
* Built business-focused dashboards.

### 6. Reporting & Presentation

* Documented key findings and insights.
* Prepared business report.
* Created presentation slides using Gamma.

## How to Run

### Prerequisites

* Python 3.x
* Jupyter Notebook
* PostgreSQL/MySQL/SQL Server
* Power BI Desktop

### Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/project-name.git
```

2. Navigate to the project directory:

```bash
cd project-name
```

3. Install required libraries:

```bash
pip install -r requirements.txt
```

4. Open Jupyter Notebook:

```bash
jupyter notebook
```

5. Run the analysis notebook.

6. Execute SQL scripts in your database environment.

7. Open the Power BI dashboard file (`.pbix`) to explore visualizations.
